# Jogos para a VitrineCity — pesquisa de 08/09/2026

O usuário priorizou jogos atuais, navegador e acesso por celular. A primeira experiência implementada é a Mini Fazenda própria, sem dependência de um servidor de jogo externo ou instalação no aparelho.

| Opção | Compatibilidade e decisão | Fonte primária |
| --- | --- | --- |
| OpenFront | Estratégia territorial no navegador, desenvolvimento ativo em setembro de 2026. Avaliar experiência móvel e operação multiplayer separada. Código AGPL-3.0; licenças de assets exigem revisão específica antes de copiar. | https://github.com/OpenFrontIO/OpenFrontIO |
| Solaris | Estratégia galáctica HTML5, desenvolvimento ativo em setembro de 2026. Partidas longas e infraestrutura Node/MongoDB própria; não é inclusão por simples iframe. GPL-3.0. | https://github.com/solaris-games/solaris |
| Survev | Battle royale 2D no navegador, desenvolvimento ativo em setembro de 2026. Exige avaliação de moderação, desempenho e infraestrutura multiplayer. GPL-3.0. | https://github.com/Survev/survev |
| Mindustry | Versão atual é aplicação Java para computador/celular. Não é compatível com inclusão direta no navegador da plataforma. GPL-3.0. A versão Classic web é antiga e não atende à prioridade de jogos atuais como atração principal. | https://mindustrygame.github.io/ · https://github.com/Anuken/Mindustry |
| HexGL | Corrida futurista HTML5 com desenvolvimento em pausa. Não escolhido como atração principal atual. | https://github.com/BKcore/HexGL |

Nenhum jogo de terceiros foi baixado ou integrado. Antes de uma integração comercial: revisar licenças de código e mídia, testar toque em aparelhos reais, definir operação de servidor/contas e só então publicar a opção como disponível.
